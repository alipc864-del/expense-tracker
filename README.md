# 💰 Expense Tracker

A modern and responsive expense tracker built with HTML, CSS and JavaScript.

## ✨ Features

- 💵 Track income and expenses
- 📊 Calculate current balance
- ➕ Add transactions
- 🗑️ Delete transactions
- 💾 Save data with LocalStorage
- 🔢 Automatic transaction count
- 📱 Responsive design
- 🌙 Modern dark UI

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🚀 About

This project was created to practice JavaScript, DOM manipulation, LocalStorage and dynamic data management.
